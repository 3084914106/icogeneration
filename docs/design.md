# 项目设计与文件职责

## app/

### main.py

备注解释：程序入口，初始化应用、创建窗口并启动事件循环；不负责图像生成、文件处理或具体 UI 逻辑。

### config.py

备注解释：保存项目配置，例如默认保存路径、图片尺寸和默认生成数量。

## ui/

### window.py

备注解释：管理主窗口，包括输入框、按钮和状态显示；它负责调用 `core/generator.py`，不承载生成流程本身。

```text
window.py
    ↓
generator.py
```

### components.py

备注解释：存放可复用的 UI 组件，例如输入框、按钮和状态显示组件。

## core/

### generator.py

备注解释：控制完整生成流程：接收用户描述、调用图片生成服务、获取图片列表、再调用转换模块。它不处理网络请求或文件保存细节。

### converter.py

备注解释：负责图片格式转换，输入为 PNG 图片路径，输出为 ICO 文件路径。

### downloader.py

备注解释：保存生成后的文件，输入为图片列表和目标目录，输出为保存后的文件列表。

## services/

### image_service.py

备注解释：负责调用外部图片生成 API，发送用户描述并获取图片结果；不负责 UI 显示或 ICO 转换。

## models/

### icon.py

备注解释：定义核心图标数据结构，供模块之间传递数据。

## utils/

### file_utils.py

备注解释：提供文件操作工具，例如创建目录、检查文件是否存在和生成文件名。

## output/

备注解释：默认生成文件保存目录。例如：

```text
output/
├── icon_001.ico
├── icon_002.ico
└── ...
```
